<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user pointer input → reel state | Pointer coordinates become an integer index into a fixed array. No string ever crosses this boundary. |
| in-page string → `speechSynthesis` | The only data leaving the page. It is always a `buildTimePhrase` return value assembled from hard-coded word tables — never user-authored text. |
| in-page string → DOM text node | The phrase is written to `textContent` on `#hora-phrase`. |

No network, storage, auth, or server boundary exists on this page.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-10 | Tampering | Phrase rendered into `#hora-phrase` | mitigate | Written with `textContent`, never `innerHTML`. Acceptance gate greps the whole file for `innerHTML`/`insertAdjacentHTML`/`document.write`/`eval`/`new Function` and fails on any hit. Even if the grammar module were altered, a text-node sink cannot execute markup. |
| T-22-11 | Tampering | Input to `SpeechSynthesisUtterance` | mitigate | `speakSpanish` is only ever called with `lastPhrase`, which is exclusively assigned from `HoraPhrase.buildTimePhrase(int, int)`. There is no free-text field, no query-string source, and no clipboard/paste path that can reach the utterance, so there is no SSML/prompt-style injection surface. |
| T-22-12 | Denial of Service | `speechSynthesis` queue flooding via rapid CTA/Repeat taps | mitigate | `speakSpanish` calls `window.speechSynthesis.cancel()` before every `speak()`, so at most one utterance is ever queued; rapid tapping replaces rather than accumulates. `resume()` prevents the queue from being left in a wedged paused state. |
| T-22-13 | Denial of Service | Pointer capture never released (stuck drag) | mitigate | `pointercancel` is registered alongside `pointerup` and runs the identical teardown, and `releasePointerCapture` is wrapped in try/catch. A dropped or cancelled gesture therefore always clears the `dragging` class and removes the document listeners rather than leaving the page in a captured state. |
| T-22-14 | Repudiation | No audit log of user actions | accept | This is a single-user client-side practice tool with no accounts, no data submission, and no consequential action to dispute. Logging would add storage surface (T-22-07) for zero benefit. |
| T-22-15 | Information Disclosure | Voice list enumeration via `speechSynthesis.getVoices()` | accept | Reading the installed voice list is a standard, already-shipped behaviour of every other page in this app (`tapvocab.js`, `numbers-quiz.html`, `quien-soy.html`). It is a browser-provided fingerprinting vector that this page neither transmits nor stores — the data never leaves the tab. |
| T-22-SC | Tampering | npm/pip/cargo installs | accept | Not applicable — zero packages installed (RESEARCH.md "Package Legitimacy Audit: Not applicable"). All code is first-party; the TTS and drag patterns are copied from files already in this repository, not fetched from any registry or CDN. |
</threat_model>
