<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user pointer/keyboard → page DOM | The only input crossing into this page. It carries no strings — reel state is an integer index into a hard-coded array. |
| repo → GitHub Pages CDN | `hora.html` and `styles.css` are publicly served static assets. |

No network boundary, no server boundary, no storage boundary: this page performs zero `fetch`/XHR, reads no query string, and writes nothing to `localStorage`/`sessionStorage` (CONTEXT.md and REQUIREMENTS.md both put persistence out of scope).

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-22-05 | Tampering | `renderReel` writing values into the reel track | mitigate | Rows are built with `document.createElement` + `textContent` only. Task acceptance gate greps `hora.html` for `innerHTML`, `insertAdjacentHTML`, `document.write`, `eval`, `new Function`, and inline `on*=` attributes and fails the task if any appears. |
| T-22-06 | Tampering | URL query string / hash | mitigate | The page never reads `location.search` or `location.hash`; dial state comes only from the hard-coded default (index 12 / index 0) and later from pointer drag. Unlike `topic.html?cat=`, there is no parameter-driven code path to poison. |
| T-22-07 | Information Disclosure | `localStorage` / `sessionStorage` | mitigate | Not used at all on this page. No practice list, no coin balance, no lives are read or written, so the page cannot leak or corrupt the state other pages own. |
| T-22-08 | Denial of Service | `renderReel` DOM churn during rapid input | accept | Each render writes exactly 5 short text nodes for a value space of at most 24 entries (RESEARCH mechanic 4). Worst case is a few hundred trivial DOM writes per second on the user's own device; there is no shared resource to exhaust. |
| T-22-09 | Spoofing | `🏠 Home` navigation link | mitigate | Root-relative same-origin `href="/"`, no `target="_blank"`, no user-controlled URL component — no reverse-tabnabbing and no open-redirect surface. |
| T-22-SC | Tampering | npm/pip/cargo installs | accept | Not applicable — zero packages installed (RESEARCH.md "Package Legitimacy Audit: Not applicable"). No `package.json`, no CDN `<script src="http…">`, no `@import url()`. The absence of any external script origin is asserted by the `hora.html` script-tag acceptance criteria. |
</threat_model>
