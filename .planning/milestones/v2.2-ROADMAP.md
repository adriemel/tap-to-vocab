# Milestone v2.2: Topics & Unidades

**Status:** ✅ SHIPPED 2026-09-11
**Phases:** 23-24
**Total Plans:** 8

## Overview

Add the Unidad 5B vocabulary and replace the crowded 10-button home grid with two grouped entry points — 📚 Topics and 📖 Unidades — backed by a new `topics` tagging column in `words.tsv`. Palabras is *partitioned* into topics (leftovers keep `topics: Palabras`); Unidad words are *additively* tagged so each unidad stays complete for school revision while its words also surface under a topic.

## Milestone Summary

**Decimal Phases:** None.

**Key Decisions:**

- Decision: `topics` is a 4th `words.tsv` column parsed by header name (Rationale: a file without the column, or a short row, must still load)
- Decision: Palabras partitioned, Unidades tagged additively (Rationale: Palabras is a catch-all where duplicates would be noise; unidades must stay complete for test revision)
- Decision: Three new topics only — Calendario, Comida y Bebida, Escuela; "Deportes y Ocio" proposed and declined by the user
- Decision: `?topic=` kept separate from `?cat=` (Rationale: five names exist in both columns with different row counts; merging would change existing `?cat=` bookmarks)
- Decision: Topic lists deduplicated on `es`+`de`, the practice list's word identity (Rationale: the same word lives under several unidades)
- Decision: Hub pages are static hardcoded link lists (Rationale: 9 topics and 5 unidades are a closed set; adding one is a one-line HTML edit)
- Decision: Only the 10 vocabulary buttons collapsed; the 9 tool/game buttons left untouched
- Decision: Topics/Unidades home buttons enlarged and bolded after UAT, reversing D-02 at the user's request

**Issues Resolved:**

- Phase 23 CR-01: a short data row (missing trailing `topics` cell) crashed the entire vocabulary load — guarded in `loadWords` (`aa7b587`), closing the only verification gap
- Phase 24 blank/wrong `<h1>` title on `?topic=` pages — `displayName = topic || category` fallback
- Phase 24 CR-01: topic lists showed 55 duplicate cards across topics and paid double coins — deduplicated on `es`+`de`
- Phase 24 WR-01: coin counter stale after browser Back (bfcache) and cross-tab changes — `pageshow` + `storage` listeners in coins.js
- Phase 24 WR-02: inconsistent `"practice"` detection showed a topic title over the practice list

**Issues Deferred:**

- 5 punctuation-only near-duplicates in `words.tsv` (`,` vs `;` in `de`) still show twice in their topic — hablar, el alemán, el inglés, el español, en; `la casa` needs a decision
- Topic headings show raw slugs (`Casa_Familia`, `Comida_Bebida`) — accepted as-is in UAT (24-REVIEW IN-02)
- 24-REVIEW IN-01 (bogus `category` value "topic" on topic pages), IN-03 (duplicated inline styles on the two hub pages), IN-04 (Unidad 5A/5B share an emoji)
- Phase 23 review warnings WR-02 (header rename silently disables tagging) and WR-03 (empty TSV throws an opaque error)
- Future requirements: TAG-07 Deportes y Ocio, TAG-08 Ropa, TAG-09 multi-topic selection, NAV-08 grouping the tool buttons

**Technical Debt Incurred:**

- `loadWords` still duplicates `loadTSV`'s parsing rather than delegating (23-REVIEW IN-01)
- 171 example-sentence rows deliberately carry a blank `topics` value — any future topic consumer must tolerate blanks
- Practice list remains keyed by text strings, not stable IDs (pre-existing debt; NAV-07 only guaranteed re-tagging didn't break it)
