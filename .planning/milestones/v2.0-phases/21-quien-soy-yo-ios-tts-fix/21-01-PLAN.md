<objective>
Fix the iOS-specific TTS regression in quien-soy.html where the first question is not spoken on iPhone when arriving from the home screen.

Purpose: iPhone users hear silence on question 1 because iOS Safari's user-gesture audio window closes before the async data load + voice polling completes. The silent priming pattern unlocks the audio session synchronously, and replacing the polling gate with a short fixed delay avoids the iOS `voiceschanged` reliability problem.

Output: Modified quien-soy.html with three targeted changes to the inline IIFE script.

CHANGE A — Silent priming utterance (add at the very top of the IIFE, before `let _cachedSpanishVoice`):

Insert this block as the first statement inside `(function () {`:

```javascript
    // iOS Safari: prime the audio session synchronously within the navigation gesture window.
    // The page navigation tap counts as a user gesture; speak() called here unlocks audio
    // before the async data fetch completes and closes the gesture window.
    if (typeof speechSynthesis !== 'undefined') {
      try {
        var _primeUtterance = new SpeechSynthesisUtterance(' ');
        _primeUtterance.volume = 0;
        window.speechSynthesis.speak(_primeUtterance);
      } catch (e) {}
    }
```

This must come BEFORE `let _cachedSpanishVoice = null;` (currently the first statement in the IIFE).

---

CHANGE B — Add `speechSynthesis.resume()` inside `speakSpanish()`, just before `window.speechSynthesis.speak(u)`:

```javascript

```

Replace with:
```javascript
          window.speechSynthesis.resume(); // iOS: re-activate if paused by tab-switch or cancel()
          window.speechSynthesis.speak(u);
```

Note: this is the `speak(u)` at the end of the `setTimeout(function () { ... }, 100)` inside `speakSpanish`.

---

CHANGE C — Replace the `startWhenReady()` polling block with a 300ms unconditional delay:

Current code (lines ~283–290):
```javascript
      function startWhenReady() {
        if (_voicesLoaded || typeof speechSynthesis === 'undefined') {
          showQuestion(0);
        } else {
          setTimeout(startWhenReady, 50);
        }
      }
      startWhenReady();
```

Replace the entire `startWhenReady` function definition AND its call with:
```javascript
      // iOS: skip _voicesLoaded polling — voices are available after a short delay
      // even when voiceschanged fires late or not at all. 300ms is safe across devices.
      setTimeout(function () { showQuestion(0); }, 300);
```

This removes the dependency on `_voicesLoaded` for initial startup. The `_voicesLoaded`
variable and its `voiceschanged` listener at lines 66-75 can remain as-is — they are
still useful for `getSpanishVoice()` caching, just no longer a gate on startup.
